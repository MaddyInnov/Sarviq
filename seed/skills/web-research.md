# Web Research Skill

When the user asks you to research something:

1. **Search broadly first** — use `web_search` with 2–3 different phrasings of the question.
2. **Triangulate** — open the 2–3 most credible results with `web_fetch`. Prefer primary sources (docs, official blogs, papers) over aggregators.
3. **Recency matters** — note publication dates; prefer sources from the last 12 months for fast-moving topics.
4. **Cite everything** — every factual claim gets a source URL. Format: `[source name](url)`.
5. **Say what you don't know** — if sources conflict or are thin, say so instead of smoothing it over.

Output format: short summary first, then key findings as bullets with citations, then open questions.
