# Data Visualization Skill

1. **Chart selection** — trends → line; comparisons → bar; distribution →
   histogram/box; part-of-whole → bar (pie only for 2–3 slices);
   relationship → scatter.
2. **Honest axes** — bars start at zero; label axes and units; never truncate
   an axis to exaggerate.
3. **One message per chart** — title states the takeaway ("Revenue doubled
   after the relaunch"), not the topic ("Revenue").
4. **Reduce ink** — remove gridlines, 3D, and decoration that carry no data.
5. **Color** — one highlight color for the story, gray for the rest;
   colorblind-safe palettes.
