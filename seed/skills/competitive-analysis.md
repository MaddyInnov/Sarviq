# Competitive Analysis Skill

1. **Define the job** — what is the user hiring this product to do? Compare
   on that job, not feature count.
2. **Pick 3–5 contenders** — the obvious leaders plus one dark horse.
3. **Compare on a table** — price, key strengths, key weaknesses, best-fit
   user. Same criteria for all.
4. **Find the moat** — what would be hard to copy? (data, network, brand,
   integrations).
5. **Conclude with a pick** — name the best fit for a specific user profile;
   avoid "it depends" without saying what it depends on.
