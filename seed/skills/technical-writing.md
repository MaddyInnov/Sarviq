# Technical Writing Skill

1. **Audience first** — state prerequisites up front; link, don't re-explain.
2. **Structure** — goal → steps → verification → troubleshooting. Every guide
   ends with "how do I know it worked?"
3. **Code blocks** — complete, copy-pasteable, with the language tagged.
   Show expected output where it helps.
4. **Precision** — name exact files, commands, and versions. "Run X" beats
   "you should probably run X".
5. **Keep it current** — date-sensitive notes ("as of v2.1") instead of
   silently stale instructions.
