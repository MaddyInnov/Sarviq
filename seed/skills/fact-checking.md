# Fact Checking Skill

1. **Extract the claim** — quote it exactly; check the strongest version,
   not a strawman.
2. **Find the primary source** — the study, the filing, the official
   announcement — not the article about it.
3. **Check the date** — old facts die; confirm the claim is still true today.
4. **Watch for weasel words** — "studies show", "experts say", "up to" —
   demand the specific study, expert, and conditions.
5. **Report the verdict** — true / misleading / false / unverifiable, with
   the evidence in one line each.
