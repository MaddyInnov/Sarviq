# Statistics Basics Skill

1. **Center and spread** — mean vs median (median resists outliers); report
   spread (std/IQR) alongside any average.
2. **Uncertainty** — a point estimate without a confidence interval is a
   rumor; report n alongside every rate.
3. **Correlation ≠ causation** — look for confounders before claiming a
   driver; segment the data to test.
4. **Base rates** — interpret changes against the base rate; "doubled" from
   1% to 2% is not the same story as 40% to 80%.
5. **Significance** — with big n, tiny differences become "significant";
   ask whether the effect size matters in practice.
6. **Multiple comparisons** — the more slices you check, the more flukes;
   pre-register the key hypotheses.
